## Assets in the game
- **Ghost**: "Ghost Girl Animated" (https://skfb.ly/o6xVr) by Shaban Hafizsalim is licensed under Creative Commons Attribution (http://creativecommons.org/licenses/by/4.0/).
  Changes: skirt and hair merged into the body mesh, root motion locked, own textures, Unreal Engine mannequin idle / walk / jog animations retargeted to its skeleton.
- **3D props** (chairs, wheelchairs, carts, IV poles, bins, signs…): [NVIDIA SimReady Assets](https://huggingface.co/datasets/nvidia/simready-assets), CC BY 4.0. Converted from USD to GLB with Blender.
- **Mannequin animations**: Unreal Engine sample content (Epic Games), used under the Unreal Engine EULA.

## Tools used to make the game
- **Sound effects and trailer music**: made with **Audio Studio MCP by KanaWorks_AI** (https://github.com/kanaworksai-hue/audio-studio-mcp, MIT, 東京AI映像合同会社) running the **Stable Audio 3 Medium** model (Stability AI Community License).
- **Phone voice**: **Piper TTS**, set up the way **Kana's VoicePi** (MIT) does it, with the **LJSpeech** voice (public domain).
- **Engine**: Unreal Engine 5.8 (Epic Games).
- **Blender**: model conversion and trailer editing.
- **Code**: written with Claude (Anthropic).
